Privacy Policy

Last updated: 26 September 2026.

Purpose

Trading Recovery is a private recovery and backup utility operated solely for its owner's project infrastructure.

Google Drive access

The application uses the Google Drive API with the drive.file scope. This allows the application to access files that it creates or that the user explicitly makes available to it.

How data is used

Google Drive access is used only to create, verify, restore and maintain project recovery backups. Backup data is encrypted before storage.

Data sharing

The application does not sell, advertise with, or intentionally share Google user data with third parties.

Website data collection

This informational website does not intentionally collect personal information, run advertising, or use analytics.

Data retention and deletion

Recovery files remain in the owner's Google Drive until the owner removes them in accordance with the project's backup and recovery procedures.

Contact

Privacy or support requests may be directed to the support contact shown on the application's Google OAuth consent screen.
