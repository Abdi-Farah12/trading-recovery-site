Trading Recovery

Trading Recovery is a private recovery and backup utility used by its owner to maintain encrypted project recovery copies in Google Drive.

The application uses the Google Drive API with the limited drive.file permission. This permits it to access files that the application creates or that the user explicitly makes available to it.

Backup contents are encrypted by the backup software before being stored in Google Drive. This website does not provide trading services, collect customer data, or offer access to the underlying project.
